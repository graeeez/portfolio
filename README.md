# Graciella E. Pastoral — Creative Portfolio

An interactive, animation-rich personal portfolio built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **Framer Motion**.

## Color Palette
- **Ice White Canvas**: `#F4F6FF`
- **Sunburst Gold**: `#F3C623`
- **Tangerine Amber**: `#EB8317`
- **Deep Navy**: `#10375C`

## Animation & UX Principles
- **Three.js 3D Scene** (`cloudai-x/threejs-skills` inspired): `THREE.Clock` delta-driven procedural motion, exponentially damped pointer parallax, DPR-capped WebGL rendering, full resource disposal, and `prefers-reduced-motion` support.
- **UI/UX Pro Max** (`nextlevelbuilder/ui-ux-pro-max-skill` inspired): Bento grid hierarchy, spring-physics filter indicators, GPU-accelerated `transform`/`opacity` transitions, scroll progress indicator, and accessible contrast.
